# Regulatory Compliance for VMware Telco Cloud Platform 5.1

Broadcom provides guidance for meeting regulatory requirements using VMware infrastructure products. This directory contains Product Applicability Guides and companion resources for VMware Telco Cloud Platform 5.1, organized by regulatory framework.

## Frameworks

### [EU Network and Information Security Directive 2 (NIS2)](nis2/)

The **Network and Information Security Directive 2 (NIS2)** (Directive 2022/2555) is the EU's updated cybersecurity framework, replacing the original NIS Directive (2016/1148) and broadening the sectors it covers. Covered entities must implement technical, operational, and organizational measures for incident handling, supply chain security, encryption, and business continuity.

- [Product Applicability Guide (PDF)](https://raw.githubusercontent.com/vmware/vcf-security-and-compliance-guidelines/main/regulatory-compliance/telco-cloud-platform/5.1/nis2/telco-cloud-platform-51-eu-nis2.pdf)

### [NIST SP 800-53 Revision 5](nist-800-53-r5/)

**NIST Special Publication 800-53 Revision 5: Security and Privacy Controls for Information Systems and Organizations** is the National Institute of Standards and Technology's catalog of security and privacy controls. Released in September 2020, Revision 5 decouples the controls from a purely federal focus and is also used by organizations outside the US government.

- [Product Applicability Guide (PDF)](https://raw.githubusercontent.com/vmware/vcf-security-and-compliance-guidelines/main/regulatory-compliance/telco-cloud-platform/5.1/nist-800-53-r5/telco-cloud-platform-51-nist-800-53-r5.pdf)

### [UK Telecommunications Security Code of Practice](uk-tsa-cop/)

The **Telecommunications Security Code of Practice** is the technical implementation guide for the *Telecommunications (Security) Act 2021* and the *Electronic Communications (Security Measures) Regulations 2022*. It establishes security standards for public telecommunications providers to support the resilience of the UK's critical digital infrastructure.

- [Companion Guide (XLSX)](https://raw.githubusercontent.com/vmware/vcf-security-and-compliance-guidelines/main/regulatory-compliance/telco-cloud-platform/5.1/uk-tsa-cop/vcf-companion-uk-tsa-code-of-practice.xlsx)
- [Companion Guide (CSV)](https://raw.githubusercontent.com/vmware/vcf-security-and-compliance-guidelines/main/regulatory-compliance/telco-cloud-platform/5.1/uk-tsa-cop/vcf-companion-uk-tsa-code-of-practice.csv)
