# Zero Trust Architecture and VMware Cloud Foundation 9.1

This directory contains a whitepaper on zero trust architecture and how VMware Cloud Foundation (VCF) 9.1 and its separately licensed advanced services support zero trust at the infrastructure layer. The whitepaper uses common zero trust reference models, including the US Department of Defense Zero Trust capability framework and NIST SP 800-207.

- [**vcf-91-zero-trust-architecture.pdf**](vcf-91-zero-trust-architecture.pdf?raw=true) - the whitepaper

The related compliance companion guide for NIST SP 800-207 is in [../nist-800-207/](../nist-800-207/).
